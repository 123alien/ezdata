# 物联网设备数据导出功能使用指南

## 功能概述

在数据模型仪表板的"物联网设备概览"部分，新增了数据导出功能，允许用户将设备的历史数据导出为CSV格式的报表文件。

## 使用方法

### 1. 选择设备和时间范围
- 在设备下拉框中选择要导出数据的设备（如：07室环境监测、08室电表等）
- 使用时间选择器选择要导出的时间范围
- 可以使用快捷时间选择按钮（今日、近7天、近30天等）

### 2. 导出数据
- 点击"导出数据报表"按钮
- 系统会自动获取选定时间范围内的所有设备数据
- 生成CSV文件并自动下载到本地

## 导出文件格式

### 文件命名规则
```
{设备名称}_{开始日期}_{结束日期}_数据报表.csv
```
例如：`07室环境监测_2024-01-15_2024-01-16_数据报表.csv`

### CSV文件结构
| 列名 | 说明 | 单位 |
|------|------|------|
| 时间 | 数据采集时间 | - |
| 设备名称 | 设备标识 | - |
| CO2 | 二氧化碳浓度 | ppm |
| PM10 | PM10颗粒物浓度 | μg/m³ |
| PM25 | PM2.5颗粒物浓度 | μg/m³ |
| TEM | 温度 | ℃ |
| RH | 相对湿度 | % |
| power | 功率/电量 | kWh |

### 数据特点
- 按时间顺序排列
- 缺失数据用空值表示
- 支持UTF-8编码，包含BOM头，确保中文正确显示
- 所有数值用双引号包围，确保CSV格式正确

## 注意事项

1. **数据范围限制**：如果选定时间范围内没有数据，系统会提示"当前时段无数据可导出"
2. **文件大小**：大量数据导出可能需要一些时间，请耐心等待
3. **浏览器兼容性**：建议使用现代浏览器（Chrome、Firefox、Edge等）
4. **数据完整性**：导出的数据与图表显示的数据保持一致

## 技术实现

- 前端使用Vue 3 + TypeScript
- 数据获取通过现有的`getDeviceMetrics` API
- CSV生成和下载使用原生JavaScript Blob API
- 支持自动重试机制（如果当前时段无数据，会自动回退查询近90天数据）

## 故障排除

### 常见问题
1. **导出按钮无响应**：检查是否已选择设备和时间范围
2. **下载失败**：检查浏览器是否阻止了文件下载
3. **数据不完整**：确认选择的时间范围内确实有数据
4. **中文乱码**：确保使用支持UTF-8的软件打开CSV文件
